# 🏨 Royal Stay — Luxury Hotel Website

A modern, elegant, and responsive hotel website designed to provide a premium online experience for hotel guests.

Royal Stay showcases beautiful rooms, hotel facilities, an image gallery, and convenient booking options through a clean and user-friendly interface.

## 🌐 Live Demo

**[Visit Royal Stay Website](https://arppra2007-lgtm.github.io/royal-stay/)**

## ✨ Features

- 🏨 Modern and elegant hotel website design
- 📱 Responsive layout for different screen sizes
- 🛏️ Hotel room showcase
- 🏊 Hotel facilities and amenities section
- 🖼️ Beautiful image gallery
- 💬 WhatsApp booking option
- 🎨 Clean and professional user interface
- ⚡ Lightweight frontend built with HTML, CSS, and JavaScript

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Interactive functionality |
| GitHub Pages | Website hosting |

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/arppra2007-lgtm/royal-stay.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation is required.

## 🎯 Project Purpose

Royal Stay was developed as a hotel website portfolio project to demonstrate frontend web development skills, responsive design, and modern website presentation.

The project focuses on creating an attractive digital presence for hotels and hospitality businesses.
